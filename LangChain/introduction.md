# LangChain
LangChain is an open-source framework used to build applications powered by Large Language Models (LLMs). It provides a set of reusable components that help developers integrate LLMs with external systems and build AI applications such as chatbots, agents, RAG systems, document Q&A systems, and workflow automation.

### Some of the key components of LangChain include:

- Chat Models and LLM integrations (OpenAI, Anthropic, Gemini, etc.)
- Prompt Templates for managing prompts
- Output Parsers for structured responses
- Memory and Chat History management
- Document Loaders for reading files and data sources
- Text Splitters for chunking documents
- Embedding Models
- Vector Databases for semantic search
- Retrievers for fetching relevant information
- Chains for combining multiple steps
- Tools for interacting with external systems
- Agents for dynamic decision-making and tool usage
- Streaming support for real-time responses
- Callbacks and Observability for monitoring execution

### LangChain is organized into several key modules:

**1. Core**
The core components that form the foundation of LangChain.

**2. LangChain Community**
A collection of community-contributed integrations, modules, and tools that extend the functionality of LangChain.

**3. Prompt Layer**
Tools for managing prompts, including prompt templates, output parsers, and prompt optimization utilities.

**4. Callbacks & LangSmith**
Tools for monitoring, debugging, and tracing LLM application execution, including LangSmith for observability.

**5. LangChain Expression Language (LCEL)**
A declarative way to compose chains, enabling advanced features like streaming, async support, and parallel processing.

**6. LangGraph**
A library for building stateful, multi-agent applications with custom control flow, including looping and conditional logic.

**7. LangChain Core (JS/TS)**
The core runtime and abstractions for JavaScript and TypeScript applications.

**8. LangChain Community (JS/TS)**
Community-contributed modules and integrations for JavaScript/TypeScript.

**9. LangChain Expression Language (LCEL - JS/TS)**
Declarative composition for JavaScript/TypeScript.

**10. LangGraph (JS/TS)**
Stateful, multi-agent application development for JavaScript/TypeScript.

**11. LangSmith**
A development platform for debugging, tracing, evaluating, and monitoring LLM applications.
